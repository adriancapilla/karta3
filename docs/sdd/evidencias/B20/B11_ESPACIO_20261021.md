Después se mantienen BAJO aceptado y Jugar habilitado; se lleva la página del actor al frente, se enfoca el botón, se exige foco/habilitación y se envía Space mediante teclado nativo. Se comprueban receptores de keydown/keyup/click con isTrusted, una única solicitud, carta correcta, plays1 y cambio de turno. No clic alternativo, force, invocación del callback, espera fija, tolerancia, ampliación de plazo o reintento.

Se conserva por separado el adverso de escritura retenida: cero jugadas, ausencia de envío diferido y aviso de incertidumbre/recuperación, como exige el contrato vigente. El montaje negativo espera la respuesta real de recuperación iniciada al vencer el ack antes de examinar el aviso; no modifica el timeout de producto5s, el de aserciones ni el del test.
